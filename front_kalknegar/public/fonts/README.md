# B-Yekan Font Files

This directory contains the B-Yekan Persian/Farsi font files for the ORBAT project.

## ✅ Current Status: Real Font Files Installed

The following B-Yekan font files are now available:
- **Yekan.woff2** - B-Yekan Regular (WOFF2 format) - ✅ Real file
- **Yekan.woff** - B-Yekan Regular (WOFF format) - ✅ Real file
- **Yekan-Bold.woff2** - B-Yekan Bold (WOFF2 format) - ✅ Real file
- **Yekan-Bold.woff** - B-Yekan Bold (WOFF format) - ✅ Real file

These fonts are used for Persian text display throughout the application and are synchronized with the frontend font files.
