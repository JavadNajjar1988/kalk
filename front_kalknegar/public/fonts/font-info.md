# B-Yekan Font Files

This directory contains B-Yekan font files for Persian text display.

Files:
- Yekan.woff2 (Modern web font format)
- Yekan.woff (Legacy web font format)
- Yekan-Bold.woff2 (Bold variant)
- Yekan-Bold.woff (Bold legacy format)

Font source: B-Yekan by Behdad Esfahbod
