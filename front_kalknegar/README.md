# نقشه‌کش آرایش نبرد

نقشه‌کش آرایش نبرد یک وب اپلیکیشن سمت کلاینت است که به شما امکان ساخت آرایش نبرد (ORBAT) و ترسیم موقعیت واحدها روی نقشه را می‌دهد. با نقشه‌کش آرایش نبرد می‌توانید نبردهای تاریخی و سناریوهای نظامی را در مرورگر خود بازسازی کنید.

**لطفاً توجه داشته باشید که این پروژه در حال توسعه است.** می‌توانید نسخه در حال توسعه را در آدرس https://orbat-mapper.app/ امتحان کنید و مستندات را در آدرس https://docs.orbat-mapper.app/ مطالعه کنید.

_تصویر نمونه:_

![تصویر نمونه در حال توسعه](images/screenshot-2023-09-01.png "تصویر نمونه در حال توسعه")

نقشه‌کش آرایش نبرد یک پروژه متن‌باز با مجوز MIT است، که به این معنی است که کد منبع آزادانه برای استفاده، تغییر و توزیع مجدد تحت شرایط مجوز در دسترس است.

شما می‌توانید یک فورک ایجاد کنید و نقشه‌کش آرایش نبرد را متناسب با نیازهای خود تطبیق دهید، اما لطفاً توجه داشته باشید که پروژه در حال حاضر در مرحله تکامل سریع با تغییرات مکرر در کدبیس قرار دارد.

## شروع کار

اگر می‌خواهید نقشه‌کش آرایش نبرد را به صورت محلی اجرا کنید یا نسخه خود را توسعه دهید، می‌توانید با دنبال کردن این مراحل این کار را انجام دهید:

کلون کردن مخزن:

    $ git clone https://github.com/orbat-mapper/orbat-mapper.git

رفتن به ریشه پروژه:

    $ cd orbat-mapper

نصب وابستگی‌ها:

    $ npm install

برای شروع سرور توسعه اجرا کنید:

    $ npm run dev

نقشه‌کش آرایش نبرد اکنون روی http://localhost:5173/ در حال اجرا است. هر تغییری که در کد منبع ایجاد کنید بلافاصله در مرورگر در دسترس خواهد بود به لطف جایگزینی سریع ماژول Vite.

برای ساخت بهینه‌شده و فشرده اجرا کنید:

    $ npm run build

دستور بالا خروجی ساخت بهینه‌شده را در دایرکتوری `dist` قرار می‌دهد. سپس می‌توانید ساخت بهینه‌شده را به صورت محلی با اجرای دستور زیر سرو کنید:

    $ npm run preview

برای گزینه‌های مختلف استقرار به https://vitejs.dev/guide/static-deploy.html مراجعه کنید.

## استفاده از نقشه‌کش آرایش نبرد بدون اتصال اینترنت

نقشه‌کش آرایش نبرد یک وب اپلیکیشن استاتیک سمت کلاینت است و با برخی تغییرات پیکربندی می‌تواند بدون اتصال اینترنت استفاده شود. با این حال، به طور پیش‌فرض نقشه‌کش آرایش نبرد از نقشه‌های میزبانی‌شده در اینترنت و سرویس آنلاین برای جستجوی نام مکان‌ها استفاده می‌کند. بنابراین اگر می‌خواهید از نقشه‌کش آرایش نبرد بدون اتصال اینترنت استفاده کنید، باید نقشه‌های خود را تهیه کنید و آن‌ها را به صورت محلی میزبانی کنید.

امکان پیکربندی نقشه‌های پیش‌فرض با دنبال کردن دستورالعمل‌های بخش بعدی وجود دارد. برای جستجوی نام مکان‌ها در حال حاضر راه‌حل ساده‌ای برای حالت آفلاین وجود ندارد.

### پیکربندی لایه‌های نقشه پیش‌فرض

می‌توانید لایه‌های نقشه پیش‌فرض را با تغییر فایل [`public/config/mapConfig.json`](public/config/mapConfig.json) پیکربندی کنید. هنگام ساخت اپلیکیشن، فایل `mapConfig.json` به `dist/config/mapConfig.json` کپی می‌شود. همچنین می‌توانید لایه‌های نقشه پایه را با تغییر مستقیم فایل `dist/config/mapConfig.json` پیکربندی کنید، اما در نظر داشته باشید که دایرکتوری `dist` هنگام ساخت اپلیکیشن بازنویسی می‌شود.

فایل `mapConfig.json` شامل یک آرایه JSON از لایه‌های نقشه پایه است. مثال:

```json
[
  {
    "title": "OSM (DE)",
    "name": "osm-de",
    "layerSourceType": "osm",
    "sourceOptions": {
      "url": "https://tile.openstreetmap.de/{z}/{x}/{y}.png",
      "crossOrigin": "anonymous"
    }
  },
  {
    "title": "نقشه توپوگرافی نروژ",
    "name": "kartverketTopo4",
    "layerSourceType": "xyz",
    "sourceOptions": {
      "crossOrigin": "anonymous",
      "url": "https://cache.kartverket.no/v1/wmts/1.0.0/topo/default/webmercator/{z}/{y}/{x}.png",
      "attributions": "<a href=\"http://www.kartverket.no/\">Kartverket</a>"
    },
    "tileLayerConfig": {
      "extent": [2, 57, 33, 72]
    }
  }
]
```

برای مروری بر گزینه‌های پیکربندی موجود، نوع `LayerConfigFile` را در [`layerConfigTypes.ts`](src/geo/layerConfigTypes.ts) ببینید.

### میزبانی نقشه‌های خود

میزبانی محلی نقشه می‌تواند به روش‌های مختلفی انجام شود، از یک سرور وب محلی ساده که درخت دایرکتوری کش‌شده کاشی‌های نقشه را سرو می‌کند تا یک سرور نقشه کامل. برخی گزینه‌ها برای بررسی:

- [TileServer GL](https://tileserver.readthedocs.io/en/latest/). [آموزش](https://openmaptiles.org/docs/host/tileserver-gl/).
- [MapProxy](https://mapproxy.org/)
- [GeoServer](https://geoserver.org/)
- [MapTiler](https://www.maptiler.com/data/)
