# دستورالعمل نصب و راه‌اندازی سیستم ODINv2

## مرحله 1: نصب وابستگی‌ها

ابتدا وابستگی‌های جدید را نصب کنید:

```bash
cd front_kalknegar
npm install
```

این دستور وابستگی‌های زیر را نصب می‌کند:
- `@syncpoint/signal@^1.3.0` - برای reactive programming
- `jsts@^2.12.1` - برای محاسبات هندسی
- `ramda@^0.31.3` - برای برنامه‌نویسی تابعی
- `proj4@^2.19.10` - برای تبدیل سیستم‌های مختصات

## مرحله 2: اجرای پروژه

```bash
npm run dev
```

## مرحله 3: دسترسی به صفحه تست

1. به صفحه Landing Page بروید
2. روی دکمه "تست سیستم نمادهای ODINv2" کلیک کنید
3. یا مستقیماً به آدرس `/odin-symbol-test` بروید

## مرحله 4: تست

در صفحه تست می‌توانید:
- روی دکمه "افزودن نمونه‌ها" کلیک کنید تا نمونه‌های مختلف نمادها اضافه شوند
- روی دکمه "پاک کردن" کلیک کنید تا همه نمادها حذف شوند
- نقشه را zoom و pan کنید

## وضعیت فعلی

✅ **مرحله 1 (نسخه ساده)**: تکمیل شده
- صفحه تست ایجاد شده
- دکمه در Landing Page اضافه شده
- Route اضافه شده
- استفاده از @syncpoint/signs برای نمادهای نقطه‌ای

⏳ **مراحل بعدی** (برای توسعه کامل):
- کپی فایل‌های کامل ODINv2
- تبدیل به TypeScript
- ایجاد adapter کامل
- پشتیبانی از نمادهای خطی و چندوجهی پیچیده

- در حال حاضر فقط نمادهای نقطه‌ای با @syncpoint/signs کار می‌کنند

- برای استفاده کامل از سیستم ODINv2، باید مراحل بعدی را انجام دهید
