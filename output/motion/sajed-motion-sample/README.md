# نمونه پنج‌ثانیه‌ای موشن ساجد

این پروژه مستقل، یک نمونه کوتاه برای آزمودن زبان بصری موشن ساجد است. نما با تصویر واقعی رابط نقشه آغاز می‌شود، مسیر و نشانگرهای زمان‌مند را نمایش می‌دهد و سپس به تصویر مفهومی زمین سه‌بعدی می‌رسد.

تصویر سه‌بعدی این نمونه، تصویر مفهومی است و نباید به‌عنوان تصویر واقعی شبیه‌ساز محصول منتشر شود.

## مشخصات

- مدت: پنج ثانیه
- نرخ قاب: سی قاب در ثانیه
- وضوح: `1920 × 1080`
- شناسه ترکیب: `SajedFiveSecondTeaser`
- صدا: ندارد
