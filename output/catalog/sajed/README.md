# کاتالوگ تصویری ساجد

این پوشه شامل سیزده صفحه تصویری عمودی برای معرفی ساجد است. متن‌ها از فایل راهنمای معرفی ساجد استخراج و برای صفحه‌آرایی کاتالوگ خلاصه شده‌اند.

## صفحه‌ها

۱. جلد
۲. ساجد چه کاری انجام می‌دهد؟
۳. عملیات در بستر نقشه و زمان
۴. ترسیم و علائم تاکتیکی
۵. ساختار یگان‌ها و منابع
۶. فازها، اهداف و وظایف
۷. رویدادها روی خط زمانی
۸. شرایط محیطی و آب‌وهوایی
۹. بازپخش عملیات
۱۰. شبیه‌ساز سه‌بعدی عملیات
۱۱. بازآفرینی عملیات‌های گذشته
۱۲. ویژگی‌های فنی و مدیریتی
۱۳. صفحه پایانی

تصویر زمینه جلد با ابزار داخلی تولید تصویر ساخته شده است. متن فارسی، صفحه‌آرایی و تصاویر رابط محصول به‌صورت جداگانه و قطعی روی آن قرار گرفته‌اند. این تصویر مفهومی سند تاریخی یا تصویر واقعی محیط سه‌بعدی محصول نیست.

## مشخصات تولید تصویر زمینه

- کاربرد: زمینه جلد کاتالوگ عمودی
- مرجع ساختار: تصویر نمونه ارائه‌شده از سوی کاربر
- مرجع محتوایی: تصویر رابط نقشه و خط زمانی پروژه
- سبک: کاتالوگ فناوری عملیاتی با زمینه سرمه‌ای، سبز خاکی و تأکید کهربایی
- ترکیب: گذار بصری از نقشه دوبعدی و خط زمانی به عوارض سه‌بعدی
- محدودیت: بدون متن، نشان تجاری، پرچم، صحنه درگیری و علائم حساس‌نما

فایل `catalog.html` نسخه صفحه‌آرایی‌شده و قابل ویرایش است. فایل `render-catalog.mjs` برای بازتولید تصاویر صفحه‌ها استفاده می‌شود.
