# تحلیل زبان‌های برنامه‌نویسی و کتابخانه‌های ODINv2

## زبان‌های برنامه‌نویسی

### 1. JavaScript (ES6+)
- **زبان اصلی**: تمام کدها به زبان **JavaScript** نوشته شده‌اند
- **نسخه**: ES6+ (ECMAScript 2018)
- **ویژگی‌ها**:
  - استفاده از `import/export` (ES Modules)
  - Arrow Functions
  - Destructuring
  - Template Literals
  - Async/Await
  - Classes

### 2. JSX (React)
- برای ساخت رابط کاربری از **JSX** استفاده می‌شود
- JSX به وسیله Babel به JavaScript تبدیل می‌شود

### 3. CSS
- برای استایل‌دهی از **CSS** استاندارد استفاده می‌شود
- فایل‌های CSS در کنار کامپوننت‌های React قرار دارند

---

## پلتفرم و فریمورک اصلی

### Electron
- **نسخه**: ^38.2.1
- **نوع**: فریمورک دسکتاپ
- **توضیح**: ODINv2 یک اپلیکیشن دسکتاپ است که با Electron ساخته شده
- **معماری**:
  - **Main Process**: کدهای در `src/main/` (Node.js)
  - **Renderer Process**: کدهای در `src/renderer/` (Browser + React)

## ساختار کلی پروژه

```
ODINv2-main/
├── src/
│   ├── main/          # Electron Main Process (Node.js)
│   ├── renderer/      # Electron Renderer Process (Browser + React)
│   └── shared/        # کدهای مشترک بین main و renderer
├── webpack.config.js  # تنظیمات Webpack
├── babel.config.mjs   # تنظیمات Babel
└── package.json       # وابستگی‌ها و اسکریپت‌ها
```

## خلاصه

### زبان‌های اصلی:
1. **JavaScript (ES6+)** - 100% کدها
2. **JSX** - برای React Components
3. **CSS** - برای استایل‌دهی

### فریمورک‌های اصلی:
1. **Electron** - پلتفرم دسکتاپ
2. **React** - رابط کاربری
3. **OpenLayers** - نقشه

### کتابخانه‌های کلیدی:
1. **JSTS** - محاسبات هندسی
2. **Ramda** - برنامه‌نویسی تابعی
3. **@syncpoint/signs** - نمادهای نظامی
4. **LevelDB** - پایگاه داده محلی
5. **Matrix** - همکاری آنلاین

### ابزارهای Build:
1. **Webpack** - باندل کردن
2. **Babel** - تبدیل کد
3. **Electron Builder** - بیلد نهایی

## نکات مهم

1. **معماری Electron**: پروژه از معماری Main/Renderer Process استفاده می‌کند
2. **برنامه‌نویسی تابعی**: استفاده گسترده از Ramda و الگوهای functional
3. **Reactive Programming**: استفاده از Signal برای مدیریت state
4. **Offline-First**: استفاده از LevelDB برای ذخیره‌سازی محلی
5. **Collaboration**: پشتیبانی از همکاری آنلاین با Matrix
