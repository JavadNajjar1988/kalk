# Kalk - سیستم مدیریت عملیات نظامی

پروژه Kalk یک سیستم جامع برای مدیریت عملیات نظامی است که شامل:
- **Backend**: FastAPI با PostgreSQL و PostGIS
- **Dashboard**: React-based frontend
- **KalkNegar**: Vue-based mapping tool

## راه‌اندازی سریع

برای راه‌اندازی یکدست روی همه سیستم‌ها، از راهنمای یکدست‌سازی استفاده کنید:

### روش 1: استفاده از اسکریپت یکدست (پیشنهادی)

```powershell
# بررسی پیش‌نیازها
.\check-prerequisites.ps1

# راه‌اندازی کامل سیستم
.\start.ps1
```

## مستندات

- **[راهنمای یکدست‌سازی](UNIFIED_SETUP_GUIDE.md)** - برای اطمینان از اجرای یکدست روی همه سیستم‌ها
- **[راهنمای تنظیمات محیطی](ENV_SETUP.md)** - تنظیم فایل `.env`
- **[راهنمای نصب](SETUP_GUIDE.md)** - نصب و راه‌اندازی اولیه
- **[راهنمای Docker](DOCKER_SETUP.md)** - استفاده از Docker

## پورت‌های استفاده شده

- **Dashboard**: `3000`
- **KalkNegar**: `5180` (مستقیم) یا `3000/kalknegar` (از طریق Dashboard)
- **Backend API**: `8000`
- **Database**: `5432` (فقط داخلی)
- **TileServer**: `8480` (با profile `maps`)
- **Keycloak**: `9090` (با profile `keycloak`)

## پیش‌نیازها

- **Node.js**: >= 20.10.0 (پیشنهادی) یا >= 18.0.0 (حداقل)
- **npm**: >= 9.0.0
- **Docker Desktop**: آخرین نسخه
- **Docker Compose**: v2.x
- **Git**: برای کلون کردن پروژه

## عیب‌یابی

اگر پروژه روی برخی سیستم‌ها اجرا نمی‌شود:

1. **بررسی پیش‌نیازها**: `.\check-prerequisites.ps1`
2. **بررسی نسخه‌ها**: مطمئن شوید همه سیستم‌ها از نسخه‌های یکسان استفاده می‌کنند
3. **بررسی پورت‌ها**: مطمئن شوید پورت‌های مورد نیاز آزاد هستند
4. **بررسی فایل .env**: مطمئن شوید فایل `.env` وجود دارد و تنظیمات صحیح است

برای جزئیات بیشتر، به [راهنمای یکدست‌سازی](UNIFIED_SETUP_GUIDE.md) مراجعه کنید.

## پشتیبانی

در صورت بروز مشکل:
1. خروجی `check-prerequisites.ps1` را بررسی کنید
2. لاگ‌های Docker را بررسی کنید: `docker compose logs`
3. نسخه‌های نصب شده را با راهنما مقایسه کنید
