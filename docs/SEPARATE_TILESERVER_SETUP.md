# راهنمای راه‌اندازی سرور نقشه جداگانه برای 10+ ترابایت

این راهنما نحوه راه‌اندازی یک **TileServer-GL جداگانه** روی هارد خارجی و اتصال آن به سیستم از طریق SDI را توضیح می‌دهد.

## ⚡ روش سریع (توصیه می‌شود)

سرور نقشه جداگانه **از قبل در `docker-compose.yml` تعریف شده است** و فقط نیاز به فعال‌سازی دارد!

### مرحله 1: تنظیم مسیر هارد خارجی

در فایل `.env` (در ریشه پروژه) مسیر هارد خارجی را تنظیم کنید:

```env
# Windows
EXTERNAL_MAPS_PATH=D:/maps

# Linux/Mac
# EXTERNAL_MAPS_PATH=/mnt/maps
```

### مرحله 2: راه‌اندازی سرور نقشه جداگانه

```powershell
# فقط سرور نقشه خارجی را راه‌اندازی کنید
docker compose --profile heavy-maps up -d external-tileserver

# یا همه سرویس‌ها به همراه سرور نقشه خارجی
docker compose --profile heavy-maps --profile maps up -d
```

سرور روی **پورت 8481** راه‌اندازی می‌شود: `http://127.0.0.1:8481`

### مرحله 3: ثبت در سیستم SDI

در داشبورد:

1. **Resources → Maps → تب Sources**
2. در بخش "SDI Servers" روی "افزودن سرور جدید" کلیک کنید
3. تنظیمات:
   - **نام**: `External TileServer (Heavy Maps)`
   - **Base URL**: `http://127.0.0.1:8481` (یا IP سرور اگر روی سرور دیگری است)
   - **Service Types**: `["XYZ"]`
   - **Auth Type**: `none`
4. روی **Test Connection** کلیک کنید
5. روی **Harvest** کلیک کنید تا لایه‌ها را دریافت کند

## جزئیات فنی

سرور نقشه جداگانه (`external-tileserver`) در `docker-compose.yml` با این ویژگی‌ها تعریف شده است:

- **پورت**: `8481` (جدا از tileserver اصلی که روی 8480 است)
- **حافظه**: حداکثر 8GB، حداقل 2GB
- **Volume**: از `EXTERNAL_MAPS_PATH` استفاده می‌کند
- **Profile**: `heavy-maps` و `external-storage`
- **مستقل**: نیازی به api ندارد

## تنظیمات پیشرفته

### استفاده از Nginx Reverse Proxy

برای عملکرد بهتر و امنیت بیشتر:

```nginx
# nginx.conf
server {
    listen 80;
    server_name tileserver.local;

    location / {
        proxy_pass http://127.0.0.1:8481;  # پورت سرور نقشه خارجی
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### تنظیمات محیطی

در `.env` سیستم اصلی:

```env
# URL سرور نقشه خارجی
EXTERNAL_TILESERVER_URL=http://192.168.1.100:8481
# یا
EXTERNAL_TILESERVER_URL=http://tileserver.local:80
```

### Load Balancing (برای حجم خیلی زیاد)

اگر چند سرور نقشه دارید، می‌توانید از nginx برای load balancing استفاده کنید.

## عیب‌یابی

### مشکل: سرور نقشه در دسترس نیست
```powershell
# بررسی وضعیت
docker ps | Select-String external-tileserver

# بررسی لاگ
docker logs kalk-external-tileserver

# تست دسترسی
Invoke-WebRequest http://127.0.0.1:8481/health

# بررسی که سرور در حال اجرا است
docker compose --profile heavy-maps ps
```

### مشکل: لایه‌ها Harvest نمی‌شوند
- بررسی کنید که TileServer در حال اجرا باشد
- بررسی کنید که URL درست باشد
- از Test Connection استفاده کنید

### مشکل: عملکرد کند
- بررسی کنید که هارد خارجی به صورت SSD باشد
- بررسی منابع سیستم (CPU, RAM)
- از Nginx caching استفاده کنید
