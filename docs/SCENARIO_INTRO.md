# اینترو سناریو (کالک‌نگار)

## هدف

برای هر سناریو می‌توان یک **ویدئوی معرفی** به‌همراه **عنوان** و **خلاصهٔ متنی** تعریف کرد. هنگام باز شدن سناریو در **کالک‌نگار** (`front_kalknegar`)، اگر ویدئو تنظیم شده باشد، برای کاربر **بار اول** یک پاپ‌آپ با پخش ویدئو، خلاصه، دکمه‌های **پخش/توقف**، **رد کردن / شروع سناریو** و گزینهٔ **«این توضیحات را دیگر نشان نده»** نمایش داده می‌شود.

پس از بستن پاپ‌آپ (با هر روش، از جمله دکمهٔ ضربدر)، وضعیت مشاهده در سرور ثبت می‌شود. اگر کاربر «عدم نمایش مجدد» را نزده باشد، دکمهٔ شناور **«اینترو سناریو»** برای پخش دوباره در گوشهٔ پایین چپ نقشه نمایش داده می‌شود.

## داده‌ها (بک‌اند)

- جدول/مدل `scenarios`: فیلدهای `intro_video_url`، `intro_title`، `intro_summary`.
- جدول `scenario_intro_views`: یک ردیف به‌ازای هر `(user_id, scenario_id)` با `seen_at` و `never_show_again`.

مهاجرت: `backend/migrations/versions/0012_scenario_intro_video.py`

## API

| متد | مسیر | توضیح |
|-----|------|--------|
| `POST` | `/api/scenarios/intro-videos` | آپلود ویدئو (نقش `SUPER_ADMIN` یا `COMMANDER`) — خروجی `{ filename, url }` |
| `DELETE` | `/api/scenarios/intro-videos/{filename}` | حذف آپلود موقتِ متصل‌نشده؛ فایل متصل به سناریو قابل حذف مستقیم نیست |
| `GET` | `/api/scenarios/intro-videos/{filename}` | سرو فایل ویدئو |
| `GET` | `/api/scenarios/{id}/intro-status` | نیاز به احراز هویت؛ برمی‌گرداند `should_show_intro`, `intro_replay_available`, و فیلدهای اینترو |
| `POST` | `/api/scenarios/{id}/intro-view` | بدنه: `{ "never_show_again": bool }` — ثبت/به‌روزرسانی مشاهده |

توکن JWT باید فیلد `uid` (شناسهٔ کاربر) داشته باشد؛ در غیر این صورت بک‌اند با نام کاربری کاربر را در جدول `users` پیدا می‌کند. در حالت `DISABLE_AUTH` برای ثبت اینترو، شناسهٔ کاربر `admin` استفاده می‌شود (در صورت وجود).

## محدودیت فایل ویدئو

- پسوند: **`.mp4`** یا **`.webm`**
- حداکثر حجم در API: **۵۰ مگابایت**
- توصیه: طول حدود **۶۰–۹۰ ثانیه**

## داشبورد (مدیریت)

در صفحهٔ جزئیات سناریو، تب **«اینترو کالک‌نگار»**: آپلود ویدئو، ویرایش URL/عنوان/خلاصه و ذخیره از طریق `PUT /api/scenarios/{id}`.
فرم پیش‌نمایش و حذف ویدئو دارد و آپلودهای موقتی که ذخیره نشده‌اند را پاک می‌کند. با تغییر عنوان، خلاصه یا ویدئو، سابقهٔ مشاهدهٔ کاربران بازنشانی می‌شود تا نسخهٔ جدید اینترو در ورود بعدی نمایش داده شود.

## کالک‌نگار (اجرا)

کامپوننت `ScenarioIntroModal.vue` و منطق در `ScenarioEditorWrapper.vue`. سناریوهای `demo-*` اینتروی API ندارند.

## متغیر پیکربندی

`SCENARIO_INTRO_VIDEO_DIR` — مسیر ذخیرهٔ فایل‌های آپلود شده (پیش‌فرض: `backend/static/scenarios/intro-videos`).
