# راهنمای سریع: چه مسیری در فرم ثبت پوشه وارد کنم؟

## روش ساده (توصیه می‌شود) 🎯

### مرحله 1: باز کردن فرم
1. به **Dashboard → Resources → Maps** بروید
2. روی **"ثبت پوشه"** کلیک کنید

### مرحله 2: استفاده از Dropdown
1. در فیلد **"مسیر پوشه"** کلیک کنید
2. لیست پوشه‌های موجود نمایش داده می‌شود
3. یک پوشه را انتخاب کنید
4. مسیر به صورت خودکار وارد می‌شود ✅

---

## روش دستی (اگر dropdown کار نکرد)

### مرحله 1: ببینید Root چیست
در زیر فیلد "مسیر پوشه" می‌بینید:
```
ریشه: mnt/external-maps/
```

این یعنی `FILESYSTEM_TILE_ROOT = /mnt/external-maps` است.

### مرحله 2: مسیر نسبی وارد کنید

**مثال 1:** اگر نقشه شما در:
```
/mnt/external-maps/sat/z3/0/
```
است، وارد کنید:
```
sat
```
یا
```
sat/z3/0
```

**مثال 2:** اگر نقشه شما در:
```
/mnt/external-maps/tehran/z15/0/0/
```
است، وارد کنید:
```
tehran
```
یا
```
tehran/z15/0/0
```

---

## جدول سریع

| موقعیت نقشه شما | Root نمایش داده شده | مسیر وارد کنید |
|-----------------|---------------------|----------------|
| `/mnt/external-maps/sat` | `mnt/external-maps/` | `sat` |
| `/mnt/external-maps/sat/z3/0` | `mnt/external-maps/` | `sat/z3/0` |
| `/mnt/external-maps/tehran` | `mnt/external-maps/` | `tehran` |
| `backend/static/maps/sat` | `sat/` | (خالی) یا `z3/0` |

---

## ❌ اشتباهات رایج

### ❌ مسیر کامل از هاست:
```
app/backend/static/maps/sat  ← اشتباه!
```

### ❌ مسیر absolute:
```
/mnt/external-maps/sat  ← اشتباه! (اگر Root همان است)
```

### ✅ مسیر نسبی صحیح:
```
sat  ← درست!
```

---

## نکته مهم 📌

**همیشه از مسیر نسبی استفاده کنید** که نسبت به Root نمایش داده شده باشد.

اگر Root: `mnt/external-maps/` است:
- ✅ مسیر نسبی: `sat` → نتیجه: `mnt/external-maps/sat`
- ❌ مسیر absolute: `/mnt/external-maps/sat` → خطا!

---

## عیب‌یابی سریع

**اگر dropdown خالی است:**
- مطمئن شوید که فایل‌های `.sqlitedb` در پوشه وجود دارد
- `FILESYSTEM_TILE_ROOT` را بررسی کنید
- Backend را restart کنید

**اگر خطای "مسیر خارج از محدوده" می‌دهد:**
- مسیر absolute نزنید
- فقط مسیر نسبی نسبت به Root وارد کنید

---

**خلاصه:** از dropdown استفاده کنید یا مسیر نسبی نسبت به Root را وارد کنید! 🎯
