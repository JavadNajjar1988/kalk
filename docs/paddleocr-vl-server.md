# راه‌اندازی سرویس کامل بازشناسی سند برای کالک‌یار

کالک‌یار دو روش برای خواندن تصویر دارد:

1. سرویس کامل بازشناسی سند که صفحه‌آرایی، ترتیب خواندن و متن را با مسیر
   `/layout-parsing` برمی‌گرداند.
2. بخش بینایی مدل در سرویس سازگار با رابط OpenAI که فقط نقش مسیر جایگزین را دارد.

برای سندهای چندستونه، جدول‌ها، نقشه‌ها و صفحه‌های دارای تصویر، روش نخست انتخاب اصلی است.
مدل تحلیل متن همچنان جداگانه پیشنهادهای سناریو و منابع را از متن استخراج می‌کند.

## پیش‌نیاز این رایانه

کارت گرافیک این رایانه از خانواده بلک‌ول و مدل آن `NVIDIA GeForce RTX 5060 Ti`
است. راهنمای رسمی مربوط به شتاب‌دهنده `sm120` باید استفاده شود. پیش از دریافت
تصویرها، دست‌کم چند ده گیگابایت فضای آزاد برای تصویرهای داکر، حافظه موقت و خروجی‌ها
در نظر بگیرید. اجرای هم‌زمان چند مدل نیز باید با یک سند نمونه و پایش حافظه آزموده شود.

## اجرای سرویس رسمی

مخزن رسمی را در محل جداگانه‌ای از پروژه کالک دریافت کنید و وارد این پوشه شوید:

```text
PaddleOCR/deploy/paddleocr_vl_docker/accelerators/nvidia-gpu-sm120
```

سپس فایل نمونه محیطی را کپی و سرویس‌ها را اجرا کنید:

```powershell
Copy-Item .env.example .env
docker compose up -d
```

فایل رسمی محیطی برای این سخت‌افزار باید برچسب‌های زیر را داشته باشد:

```text
API_IMAGE_TAG_SUFFIX=latest-nvidia-gpu-sm120-offline
VLM_BACKEND=vllm
VLM_IMAGE_TAG_SUFFIX=latest-nvidia-gpu-sm120-offline
```

سلامت سرویس را پیش از اتصال کالک بررسی کنید:

```powershell
Invoke-RestMethod http://127.0.0.1:8080/health
```

اگر درگاه `8080` روی سرور اشغال است، نگاشت درگاه را در فایل رسمی تغییر دهید و همان
درگاه تازه را در تنظیمات کالک وارد کنید.

## اتصال کالک

در فایل محیطی کالک این مقدار را تنظیم کنید. در اجرای داکری، نام میزبان زیر باعث
دسترسی ظرف رابط برنامه به سرویس روی ویندوز می‌شود:

```text
DOCUMENT_OCR_PIPELINE_URL=http://host.docker.internal:8080
```

دو مدل فعلی برای مسیر جایگزین و تحلیل متن نیز چنین تنظیم می‌شوند:

```text
DOCUMENT_LLM_BASE_URL=http://host.docker.internal:1234
DOCUMENT_LLM_MODEL=qwen/qwen3.5-9b
DOCUMENT_OCR_BASE_URL=http://host.docker.internal:1234
DOCUMENT_OCR_MODEL=paddlepaddle/paddleocr-vl-1.5-gguf/paddleocr-vl-1.5.gguf
```

پس از تغییر فایل محیطی، فقط رابط برنامه را بازسازی کنید:

```powershell
docker compose up -d --build api
```

در تب «کالک‌یار»، وضعیت «صفحه‌آرایی و تصویر» باید آماده باشد. اگر سرویس کامل
پاسخ ندهد، سامانه به‌صورت خودکار مسیر مستقیم مدل بینایی را به کار می‌گیرد و این
تغییر روش را در هشدار همان صفحه ثبت می‌کند.

## آزمون پذیرش پیشنهادی

پیش از بهره‌برداری، مجموعه‌ای شامل ۳۰ تا ۵۰ صفحه واقعی آماده کنید: صفحه متنی، اسکن
کم‌کیفیت، جدول، نقشه، صفحه چندستونه و صفحه دارای دست‌نویس. برای هر صفحه این موارد
اندازه‌گیری شود:

- درستی نام اشخاص، یگان‌ها، تجهیزات و مکان‌ها؛
- درستی اعداد، تاریخ‌ها و ترتیب خواندن؛
- کامل‌بودن شاهد و شماره صفحه؛
- زمان پردازش و بیشینه مصرف حافظه؛
- تعداد پیشنهادهای ردشده یا نیازمند اصلاح کاربر.

هیچ پیشنهاد استخراج‌شده‌ای نباید مستقیم وارد سناریو یا کاتالوگ منابع شود. ثبت نهایی
باید پس از بازبینی کاربر و با حفظ شماره صفحه، روش خواندن و شناسه سند انجام شود.
