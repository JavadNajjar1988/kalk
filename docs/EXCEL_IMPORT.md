# قالب اکسل استاندارد — ایمپورت سناریو و منابع

فایل قالب رسمی را از داشبورد، بخش **مدیریت داده → دانلود قالب** بگیرید (`scenario_import_template.xlsx`).

عنوان ستون‌های قالب جدید فارسی است. کاربرگ «زمان‌بندی» برای انتخاب سال، ماه و روز شمسی، ساعت، دقیقه و ناحیه زمانی استفاده می‌شود. ستون خروجی همان زمان را به میلادی نمایش می‌دهد و واردساز نیز مقدار شمسی را به زمان استاندارد تبدیل می‌کند.

هر ردیف زمان یک `شناسه_زمان` دارد. این شناسه در ستون‌های «شناسه زمان شروع»، «شناسه زمان پایان» یا «شناسه زمان» کاربرگ‌های دیگر انتخاب می‌شود.

## شیت «سناریو» (یا `scenario`)

| ستون | توضیح |
|------|--------|
| `name` / نام | عنوان سناریو (الزامی) |
| `description` / توضیح | متن توضیح |
| `start_time` / زمان شروع | ISO-8601 یا مهر زمانی میلی‌ثانیه |
| `time_zone` / منطقه زمانی | مثلاً `Asia/Tehran` یا `UTC` |
| `symbology_standard` | پیش‌فرض `app6` |

حداقل یک ردیف داده (ردیف ۲) لازم است.

در قالب فارسی، می‌توان به‌جای ورود مستقیم زمان، ستون `شناسه_زمان_شروع` را از فهرست انتخاب کرد.

## شیت «حوادث» (`events`)

| ستون | توضیح |
|------|--------|
| `id` / شناسه | اختیاری؛ در صورت خالی تولید می‌شود |
| `title` / عنوان | الزامی برای هر رویداد |
| `subtitle` / زیرعنوان | اختیاری |
| `start_time` | زمان رویداد |
| `end_time` | زمان پایان اختیاری |
| `side` | طرف مرتبط با رویداد |
| `unit_ids` | شناسه یک یا چند یگان با جداکننده ویرگول |
| `equipment_ids` | شناسه یک یا چند تجهیز با جداکننده ویرگول |
| `lon` / `lat` | اختیاری؛ نقطه روی نقشه |

برای هر رویداد، یک صحنه در استوری‌برد ساخته می‌شود. اگر مختصات رویداد ثبت شده باشد، دوربین صحنه به همان محل می‌رود.

## شیت «یگان‌ها» (`units`)

| ستون | توضیح |
|------|--------|
| `id` / شناسه | اختیاری |
| `name` / نام | الزامی |
| `parent_id` / id والد | برای درخت سازمانی؛ خالی = ریشه |
| `side` / طرف | `friend`، `hostile`، `neutral` یا معادل فارسی (دوست، دشمن، …) |
| `symbol_type` / نوع نماد | نام فارسی نماد از فهرست انتخاب؛ مانند پیاده‌نظام، زرهی یا توپخانه |
| `echelon` / رده یگان | رده اصلی سازمانی؛ از ارتش و سپاه تا لشکر، تیپ، هنگ، گردان، گروهان و دسته |
| `symbol_status` / وضعیت نماد | حاضر، برنامه‌ریزی‌شده، آسیب‌دیده یا نابودشده |
| `advanced_sidc` / کد نماد پیشرفته | اختیاری و بیست‌رقمی؛ فقط برای نماد خارج از فهرست و با اولویت بر انتخاب‌های فارسی |
| `time`، `lon`، `lat` | اختیاری برای اولین state موقعیت |

کاربر در حالت عادی طرف، رده یگان، نوع نماد و یگان والد را با عنوان فارسی انتخاب می‌کند و واردساز کد نماد و اسکلت آرایش نبرد را می‌سازد. کاربرگ «راهنمای نمادها» رده‌های اصلی را برای طرف خودی و دشمن نمایش می‌دهد. جزئیات بیشتر، زیرگروه‌ها و تغییرات تخصصی نماد پس از ورود در کالک‌نگار انجام می‌شود. ستون کد پیشرفته فقط برای موارد خارج از فهرست است.

## شیت «تجهیزات» (`equipment`)

| ستون | توضیح |
|------|--------|
| `id`، `name`، `type`، `quantity`، `unit_id` | `unit_id` ارجاع به شناسه یگان در شیت یگان‌ها |
| `start_time`، `lon`، `lat` | اگر مختصات ثبت شود، تجهیز علاوه بر اتصال به یگان به‌صورت یک عارضه مستقل روی نقشه دیده می‌شود |

## شیت «پرسنل» (`personnel`)

| ستون | توضیح |
|------|--------|
| `first_name` / `last_name` یا `full_name` | نام |
| `rank` / درجه | |
| `specialty` / تخصص | |
| `national_id` / کد ملی | |
| `unit_id` | ارجاع به یگان |

## شیت «عوارض» (`features`)

| ستون | توضیح |
|------|--------|
| `id`، `name`، `type` | شناسه ثابت، نام و دسته عارضه |
| `lon`، `lat` | مرکز عارضه؛ الزامی |
| `radius_m` | شعاع اختیاری بر حسب متر؛ در صورت خالی بودن، عارضه نقطه‌ای است |
| `start_time`، `end_time` | بازه زمانی نمایش عارضه |
| `event_id` | اتصال اختیاری به رویداد |

مرز چندضلعی در فایل اکسل ثبت نمی‌شود. کاربر مرکز و در صورت نیاز شعاع را وارد می‌کند و شکل نهایی را بعداً روی نقشه ویرایش می‌کند.

---

**API بک‌اند**

- `POST /api/data-import/scenario/preview` — پیش‌نمایش بدون ذخیره  
- `POST /api/data-import/scenario/import` — ایجاد یا تکمیل سناریو (نیاز به نقش فرمانده/سوپرادمین)
- `POST /api/data-import/resources/import` — برگرداندن JSON پرسنل/تجهیز برای ادغام در داشبورد  
- `GET /api/data-import/excel-template` — دانلود قالب  

**AI اختیاری:** `INTERNAL_LLM_BASE_URL` در `.env` بک‌اند (مثلاً آدرس سرویس سازگار با OpenAI).

در رابط مدیریت داده می‌توان سناریوی مقصد را انتخاب کرد. روش پیش‌فرض، رکوردهای هم‌شناسه را به‌روزرسانی و رکوردهای جدید را اضافه می‌کند و چیزی را که در فایل نیست حذف نمی‌کند. جایگزینی کامل نیز به‌صورت انتخاب جداگانه در دسترس است.
