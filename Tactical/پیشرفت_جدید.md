## 🎯 ساختار Services

### Global Services (برای همه)
```javascript
useServicesStore()
├── projectStore      // لیست پروژه‌ها
├── preferencesStore  // تنظیمات global
├── sessionStore      // session global
└── emitter          // event bus global
```

### Project Services (برای هر پروژه)
```javascript
initializeProjectServices(projectUUID)
├── store            // ✅ Main data store
├── jsonDB           // ✅ JSON database
├── wkbDB            // ✅ WKB geometries
├── emitter          // ✅ Project events
├── sessionStore     // ✅ Project session
├── preferencesStore // ✅ Project prefs
├── undo             // ✅ Mock (MVP)
└── selection        // ✅ Mock (MVP)
```

## 🔄 Flow اجرا

### 1. ورود به پروژه
```
User clicks project
  ↓
Router: /project/:id
  ↓
Project.vue mounts
  ↓
initializeProjectServices(id)
  ↓
Create IndexedDB: ODINv2:{id}
  ↓
Initialize Store + partitions
  ↓
Provide services to Map
  ↓
Map.vue mounts
  ↓
Create OpenLayers map
  ↓
Load vector sources (from Store)
  ↓
✅ Ready!
```

### 2. Database Structure
```
IndexedDB: ODINv2:{projectUUID}
├── tuples/         (JSON - features, layers, etc.)
├── geometries/     (WKB - geometry data)
├── preferences/    (JSON - project preferences)
└── session/        (JSON - session data)
```
