### گزینه 2: Initialize کامل Store (پیشنهادی برای آینده)
مراحل:
1. کپی کردن `Project-services.web.js` و تبدیل به Vue
2. Initialize کردن همه services در Project component
3. Provide کردن services به Map و سایر components
4. نصب `level-js` و `level` برای database

کد نمونه:
```javascript
// در Project.vue
import { provide, onMounted } from 'vue'
import { initializeProjectServices } from '../services/projectServices'

onMounted(async () => {
  const projectServices = await initializeProjectServices(route.params.id)
  provide('projectServices', projectServices)
})
```
