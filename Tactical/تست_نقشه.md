## 🐛 مشکلات احتمالی:

### **مشکل 1: Map Container ندارد height**
**علامت:** صفحه خالی، بدون خطا

**راه‌حل:**
```css
.map-container {
  position: relative;
  width: 100%;
  height: 100%;
  min-height: 500px; /* اضافه کنید */
}
```

### **مشکل 2: Tiles بارگذاری نمی‌شوند**
**علامت:** نقشه خاکستری، بدون tiles

**راه‌حل:**
- بررسی اتصال اینترنت
- بررسی Network tab برای خطاهای 404

### **مشکل 3: Map initialize نمی‌شود**
**علامت:** خطا در console

**راه‌حل:**
- بررسی services
- بررسی bootstrap

### **مشکل 4: View مشخص نیست**
**علامت:** نقشه سیاه یا خالی

**راه‌حل:**
```javascript
// در view.js
const view = new View({
  center: [0, 0],
  zoom: 2
})
```

## 🔧 دستورات تست:

## 📝 اطلاعات مورد نیاز برای عیب‌یابی:

لطفاً این اطلاعات را ارسال کنید:

1. **Console Errors:**
   - تمام خطاهای قرمز
   - تمام warnings زرد

2. **Console Logs:**
   - آخرین 20 خط log

3. **Network:**
   - آیا درخواست‌های tile می‌بینید؟
   - Status code چیست؟

4. **Elements:**
   - آیا `<canvas>` داخل `#map` هست؟
   - `width` و `height` چقدر است؟

## 🚀 تست سریع:

در Console مرورگر این کد را اجرا کنید:

```javascript
// تست 1: Map element
const mapEl = document.getElementById('map')
console.log('Map exists:', !!mapEl)
console.log('Map size:', mapEl?.offsetWidth, 'x', mapEl?.offsetHeight)

// تست 2: Canvas
const canvas = mapEl?.querySelector('canvas')
console.log('Canvas exists:', !!canvas)
console.log('Canvas size:', canvas?.width, 'x', canvas?.height)

// تست 3: OSD
const osd = document.getElementById('osd')
console.log('OSD exists:', !!osd)
```
