## 🔧 **اگر نقشه دیده نمی‌شود:**

### **تست در Console:**
```javascript
const mapEl = document.getElementById('simple-map');
console.log('Map element:', mapEl);
console.log('Map size:', mapEl?.offsetWidth, 'x', mapEl?.offsetHeight);

const canvas = mapEl?.querySelector('canvas');
console.log('Canvas:', canvas);
console.log('Canvas size:', canvas?.width, 'x', canvas?.height);
```

### **بررسی Network:**
- تب `Network` را باز کنید
- فیلتر: `Img`
- باید درخواست‌هایی برای `tile.openstreetmap.org` ببینید
