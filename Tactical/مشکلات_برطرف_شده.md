## 📋 خلاصه تغییرات

### **1. ✅ اصلاح Style در vectorLayers.js**
**مشکل:** خطای `No fill, stroke, point, or text symbolizer properties in style`

**راه‌حل:**
```javascript
// ❌ قبلی
const highlightStyle = (() => {
  return [new Style({ ... })]
})()

// ✅ اصلاح شده
const createHighlightStyle = () => {
  const fill = new Fill({ color: 'rgba(255,50,50,0.4)' })
  const stroke = new Stroke({ color: 'black', width: 1, lineDash: [10, 5] })
  const circle = new Circle({ fill, stroke, radius: 50 })
  return new Style({
    image: circle,
    fill: fill,
    stroke: stroke
  })
}
```
