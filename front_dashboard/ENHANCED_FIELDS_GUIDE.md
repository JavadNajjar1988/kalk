# راهنمای فیلدهای پیشرفته FieldManager

## بررسی اجمالی

فیلد منیجر حالا از انواع فیلدهای پیشرفته برای مدیریت بهتر اطلاعات پرسنلی پشتیبانی می‌کند. این فیلدها با اعتبارسنجی‌های خاص و قابلیت‌های پیشرفته طراحی شده‌اند.

## انواع فیلدهای پیشرفته

### 1. فیلدهای اعتبارسنجی پیشرفته

#### متن انگلیسی (`text-english`)
- **توضیح**: فقط حروف انگلیسی، فاصله، خط فاصله و آپوستروف مجاز است
- **استفاده**: برای نام‌های لاتین، عناوین انگلیسی
- **اعتبارسنجی**: Regex pattern `/^[a-zA-Z\s\-'.]+$/`

#### متن عددی (`text-numeric`)
- **توضیح**: فقط اعداد 0-9 مجاز است
- **استفاده**: برای کدهای پرسنلی، شماره‌های شناسایی
- **اعتبارسنجی**: Regex pattern `/^\d+$/`

#### کد ملی شرطی (`conditional-national-id`)
- **توضیح**: اعتبارسنجی کد ملی بر اساس تابعیت انتخاب شده
- **تابعیت‌های پشتیبانی شده**:
  - **ایرانی**: کد ملی 10 رقمی با الگوریتم چک‌سام
  - **لبنانی**: شماره شناسایی 11 رقمی
  - **عراقی**: شماره شناسایی 12 رقمی
  - **قطری**: شماره شناسایی 11 رقمی (QID)
- **وابستگی**: نیازمند فیلد تابعیت

### 2. فیلدهای آرایه‌ای

#### آرایه شماره تلفن (`phone-array`)
- **توضیح**: امکان اضافه کردن چندین شماره تلفن با برچسب‌های مختلف
- **برچسب‌ها**: موبایل، منزل، محل کار، اضطراری، فکس، سایر
- **ویژگی‌ها**:
  - انتخاب یک شماره به عنوان اصلی
  - حداقل و حداکثر تعداد قابل تنظیم
  - اعتبارسنجی فرمت شماره تلفن ایرانی
- **تنظیمات**: `minItems` (پیش‌فرض: 1), `maxItems` (پیش‌فرض: 5)

#### آرایه آدرس (`address-array`)
- **توضیح**: امکان اضافه کردن چندین آدرس با برچسب‌های مختلف
- **برچسب‌ها**: منزل، محل کار، محل تولد، موقت، سایر
- **ویژگی‌ها**:
  - انتخاب سلسله‌مراتبی موقعیت
  - آدرس دقیق
  - کد پستی
  - مختصات جغرافیایی (اختیاری)
- **تنظیمات**: `minItems` (پیش‌فرض: 0), `maxItems` (پیش‌فرض: 3)

### 3. فیلدهای سلسله‌مراتبی

#### آدرس سلسله‌مراتبی (`hierarchical-address`)
- **توضیح**: انتخاب آدرس از درخت جغرافیایی سیستم + آدرس دقیق
- **ادغام**: متصل به سیستم جغرافیایی واقعی Definition Editor
- **مراحل انتخاب**:
  1. انتخاب قاره از درخت
  2. انتخاب کشور
  3. انتخاب استان/ایالت
  4. انتخاب شهرستان
  5. ادامه تا سطح شهر (7 سطح)
  6. وارد کردن آدرس دقیق
- **ویژگی‌ها**:
  - بارگذاری خودکار داده‌ها از `geographical.json`
  - فیلتر پویای گزینه‌ها بر اساس انتخاب قبلی
  - نمایش مختصات جغرافیایی برای نودهای مهم
  - نمایش مسیر انتخاب شده به صورت تصویری
- **تنظیمات**:
  - `hierarchicalCategory`: دسته‌بندی جغرافیایی مرجع (پیش‌فرض: "geographical")
  - `allowFreeText`: اجازه متن آزاد برای آدرس

### 4. فیلدهای مرکب

#### تفکیک نام (`name-split`)
- **توضیح**: تفکیک نام و نام خانوادگی در فیلدهای جداگانه
- **فیلدها**:
  - نام (اجباری)
  - نام خانوادگی (اجباری)
- **اعتبارسنجی**: فقط حروف فارسی یا انگلیسی

#### نام دوزبانه (`full-name-dual`)
- **توضیح**: امکان وارد کردن نام به دو زبان فارسی و انگلیسی
- **فیلدها**:
  - نام فارسی (اجباری)
  - نام انگلیسی (اختیاری)
- **اعتبارسنجی**: زبان مناسب برای هر فیلد

## نحوه استفاده

### 1. اضافه کردن فیلد جدید
1. در FieldManager روی "افزودن فیلد" کلیک کنید
2. نوع فیلد مورد نظر را انتخاب کنید
3. تنظیمات مربوطه را پیکربندی کنید
4. فیلد را ذخیره کنید

### 2. پیکربندی فیلدهای آرایه‌ای
- **حداقل آیتم**: حداقل تعداد آیتم‌های مورد نیاز
- **حداکثر آیتم**: حداکثر تعداد آیتم‌های مجاز
- **مثال**: برای شماره تلفن حداقل 1 و حداکثر 5

### 3. پیکربندی آدرس سلسله‌مراتبی
- **دسته‌بندی جغرافیایی**: معمولاً "geographical"
- **اجازه متن آزاد**: برای امکان وارد کردن آدرس دستی

## مثال‌های کاربردی

### پروفایل پرسنل کامل
```json
{
  "firstName": { "type": "name-split" },
  "englishName": { "type": "text-english" },
  "personalCode": { "type": "text-numeric" },
  "nationalId": { "type": "conditional-national-id" },
  "phones": { "type": "phone-array", "minItems": 1, "maxItems": 3 },
  "addresses": { "type": "address-array", "minItems": 1, "maxItems": 2 },
  "birthPlace": { "type": "hierarchical-address" }
}
```

## نکات مهم

1. **وابستگی فیلدها**: برخی فیلدها مثل کد ملی شرطی نیازمند فیلدهای دیگر (تابعیت) هستند
2. **اعتبارسنجی**: همه فیلدهای پیشرفته دارای اعتبارسنجی خودکار هستند
3. **عملکرد**: فیلدهای آرایه‌ای برای مقادیر زیاد بهینه شده‌اند
4. **RTL**: همه فیلدها از زبان فارسی و راست‌چین پشتیبانی می‌کنند

## رفع مشکل

### مشکلات رایج
1. **خطای TypeScript**: اطمینان حاصل کنید که نوع فیلد در `equipment.ts` تعریف شده
2. **عدم نمایش فیلد**: بررسی کنید که کامپوننت فیلد در `DynamicForm` ثبت شده
3. **خطای اعتبارسنجی**: مطمئن شوید که داده ورودی با فرمت مورد انتظار مطابقت دارد
