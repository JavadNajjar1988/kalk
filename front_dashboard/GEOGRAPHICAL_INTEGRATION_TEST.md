# تست ادغام سیستم جغرافیایی واقعی

## خلاصه تغییرات

✅ **تحقق یافته**: کامپوننت `HierarchicalAddressField` با موفقیت با سیستم جغرافیایی واقعی Definition Editor ادغام شد.

## ویژگی‌های جدید

### 1. بارگذاری خودکار داده‌ها
- داده‌های جغرافیایی از `geographical.json` بارگذاری می‌شود
- سطوح سازمانی از همان فایل دریافت می‌شود
- کش کردن داده‌ها برای بهبود عملکرد

### 2. ساختار درختی 9 سطحی
```
قاره (Continent)
├── کشور (Country)
    ├── استان/ایالت (Province/State)
        ├── شهرستان/منطقه (County/District)
            ├── بخش/ناحیه (Sector/Sub-district)
                ├── دهستان/زون عملیاتی (Rural District/Operational Zone)
                    ├── روستا/شهر/پایگاه (Village/Town/Base)
                        ├── محله/قرارگاه (Neighborhood/HQ Zone)
                            ├── مختصات دقیق/منطقه پویش (Point/Grid Square/AOI)
```

### 3. انتخاب پویا و هوشمند
- فیلتر کردن گزینه‌ها بر اساس انتخاب سطوح قبلی
- غیرفعال کردن خودکار سطوح وابسته
- ریست خودکار سطوح بعدی هنگام تغییر

### 4. رابط کاربری بهبود یافته
- نمایش مسیر انتخاب شده به صورت تصویری
- نمایش مختصات جغرافیایی برای نودهای مهم
- پیام‌های راهنما و وضعیت بارگذاری
- پشتیبانی کامل از RTL

## نحوه تست

### 1. در FieldManager
1. رفتن به Definition Editor → Persons Category
2. افزودن فیلد جدید با نوع "آدرس سلسله‌مراتبی" یا "آرایه آدرس"
3. تنظیم `rootCategory` روی "geographical"
4. ذخیره فیلد

### 2. در Form Preview
1. رفتن به تب پیش‌نمایش فرم
2. کلیک روی فیلد آدرس
3. انتخاب قاره (مثلاً "آسیا")
4. انتخاب کشور (مثلاً "ایران")
5. انتخاب استان (مثلاً "تهران")
6. ادامه تا سطح شهر
7. وارد کردن آدرس دقیق

### 3. در Test Component
استفاده از `EnhancedFieldManagerTest.tsx`:
```bash
# نمایش کامپوننت تست
npm run dev
# رفتن به /test/enhanced-field-manager
```

## داده‌های نمونه موجود

سیستم شامل داده‌های زیر است:

### قاره‌ها
- آسیا
- اروپا

### کشورها
- ایران (تحت آسیا)
- عراق (تحت آسیا)  
- آلمان (تحت اروپا)

### شهرهای ایران
- تهران → شهریار، تهران
- اصفهان → اصفهان
- و سایر شهرها...

1. **محدودیت انتخاب**: تا سطح 7 (شهر) قابل انتخاب است
2. **عملکرد**: داده‌ها کش می‌شوند برای بهبود سرعت  
3. **خطایابی**: پیام‌های واضح برای خطاهای بارگذاری
