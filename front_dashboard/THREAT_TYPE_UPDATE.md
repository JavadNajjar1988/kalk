### 3. سطوح سلسله‌مراتبی تعریف شده

#### سطح 1: انواع تهدیدات اصلی

1. **تهدید متقارن (Symmetric Threat)**
   - تهدید نیروهای زمینی
   - تهدید نیروهای هوایی  
   - تهدید نیروهای دریایی

2. **تهدید نامتقارن (Asymmetric Threat)**
   - تروریسم
   - شبه‌نظامیان
   - جنگ چریکی

3. **تهدید ترکیبی (Hybrid Threat)**
   - عملیات ترکیبی
   - جنگ هیبریدی

4. **تهدید داخلی (Internal / Insurgency)**
   - شورش داخلی
   - جنگ داخلی

5. **تهدید سایبری (Cyber Threat)**
   - حمله سایبری
   - جنگ سایبری

6. **تهدید اطلاعاتی / رسانه‌ای (Info / Psy Threat)**
   - جنگ روانی
   - عملیات اطلاعاتی

7. **تهدید هسته‌ای / شیمیایی / میکروبی (CBRN)**
   - تهدید هسته‌ای
   - تهدید شیمیایی
   - تهدید بیولوژیکی

8. **تهدید محیطی / طبیعی (Environmental Threat)**
   - بلایای طبیعی
   - تغییرات اقلیمی

9. **تهدید هوشمند (Smart Threat)**
   - هوش مصنوعی
   - سلاح‌های پیشرفته

## داده‌های پیش‌فرض اضافه شده

### سطح 1: انواع تهدیدات اصلی
- **تهدید متقارن**: تهدیدات متقارن و سنتی نظامی شامل نیروهای زمینی، هوایی و دریایی
- **تهدید نامتقارن**: تهدیدات نامتقارن و غیرسنتی شامل تروریسم، شبه‌نظامیان و جنگ چریکی
- **تهدید ترکیبی**: تهدیدات ترکیبی و چندبعدی شامل عملیات ترکیبی و جنگ هیبریدی
- **تهدید داخلی**: تهدیدات داخلی و شورش‌ها شامل شورش داخلی و جنگ داخلی
- **تهدید سایبری**: تهدیدات سایبری و فضای مجازی شامل حمله سایبری و جنگ سایبری
- **تهدید اطلاعاتی / رسانه‌ای**: تهدیدات اطلاعاتی و جنگ روانی شامل جنگ روانی و عملیات اطلاعاتی
- **تهدید هسته‌ای / شیمیایی / میکروبی**: تهدیدات CBRN شامل تهدیدات هسته‌ای، شیمیایی و بیولوژیکی
- **تهدید محیطی / طبیعی**: تهدیدات محیطی و بلایای طبیعی شامل بلایای طبیعی و تغییرات اقلیمی
- **تهدید هوشمند**: تهدیدات هوشمند و پیشرفته شامل هوش مصنوعی و سلاح‌های پیشرفته

1. به مسیر `http://localhost:3000/dashboard/master-definitions/category/cat-13` بروید

3. از قابلیت‌های ویرایش، حذف و اضافه کردن آیتم‌های جدید استفاده کنید
4. سطوح سلسله‌مراتبی را مدیریت کنید
