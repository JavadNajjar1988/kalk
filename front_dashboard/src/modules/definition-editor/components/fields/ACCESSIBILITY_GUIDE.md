# راهنمای دسترس‌پذیری سیستم مدیریت فیلدها

این راهنمای جامع دسترس‌پذیری شامل بهترین شیوه‌ها و پیاده‌سازی‌های اعمال شده در سیستم مدیریت فیلدها است.

## ۱. پشتیبانی از صفحه‌خوان

### ARIA Labels و Roles
- تمام کامپوننت‌ها دارای برچسب‌های ARIA مناسب هستند
- استفاده از `role="region"` برای بخش‌های اصلی
- استفاده از `aria-label` برای توضیح عملکرد عناصر
- استفاده از `aria-required` برای فیلدهای اجباری

### ناوبری صفحه‌خوان
- ساختار منطقی HTML با استفاده از عناصر معنایی
- ترتیب تب مناسب برای حرکت بین عناصر
- اعلان تغییرات پویا با `aria-live`

## ۲. ناوبری صفحه‌کلید

### میانبرهای صفحه‌کلید
- **Escape**: بستن دیالوگ‌ها
- **Enter**: ارسال فرم در مرحله پیش‌نمایش
- **Tab**: حرکت بین عناصر قابل تمرکز

### تمرکز بصری
- نمایش واضح تمرکز روی عناصر فعال
- انیمیشن‌های ملایم برای انتقال تمرکز
- حفظ موقعیت تمرکز بین تعاملات

## ۳. سازگاری با رنگ

### کنتراست رنگ
- حداقل نسبت کنتراست 4.5:1 برای متن‌های کوچک
- استفاده از رنگ‌های دوستانه با کاربران نابینا رنگی
- ارائه اطلاعات از طریق عناصر غیررنگی

### حالت تاریک
- پشتیبانی از حالت تاریک با کنتراست مناسب
- تطبیق خودکار با تنظیمات سیستم

## ۴. پشتیبانی از اندازه‌های مختلف متن

### انعطاف‌پذیری اندازه
- استفاده از واحد‌های نسبی (rem, em)
- پشتیبانی از بزرگ‌نمایی تا ۲۰۰٪
- حفظ قابلیت استفاده در اندازه‌های بزرگ

## ۵. بهبودهای عملکردی

### کاهش حرکات
- گزینه غیرفعال‌سازی انیمیشن‌ها
- حرکات کنترل شده با `prefers-reduced-motion`

### زمان‌بندی تعاملات
- عدم ایجاد محدودیت زمانی برای تعاملات
- امکان لغو عملیات‌های طولانی

## ۶. پشتیبانی از تکنولوژی‌های کمکی

### سازگاری با ابزارها
- تست با صفحه‌خوان‌های مختلف
- پشتیبانی از کنترل‌های صوتی
- سازگاری با ماوس‌های ویژه

## ۷. بهترین شیوه‌های پیاده‌سازی

### ساختار HTML
```jsx
// مثال صحیح
<Box 
  role="region" 
  aria-label="بخش ویژگی‌های فیلد"
  tabIndex={-1}
>
  <TextField
    aria-label="عنوان فیلد"
    aria-required="true"
  />
</Box>

// مثال نادرست
<Box>
  <input placeholder="عنوان" />
</Box>
```

### مدیریت تمرکز
```typescript
// مدیریت تمرکز در دیالوگ‌ها
useEffect(() => {
  if (open && dialogRef.current) {
    const firstFocusable = dialogRef.current.querySelector(
      'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
    );
    if (firstFocusable) {
      (firstFocusable as HTMLElement).focus();
    }
  }
}, [open]);
```

### اعلان تغییرات
```typescript
// اعلان تغییرات پویا
<Typography
  aria-live="polite"
  aria-atomic="true"
>
  {previewValue.length}/{maxLength}
</Typography>
```

## ۸. تست دسترس‌پذیری

### ابزارهای تست
- **axe DevTools**: برای تست خودکار
- **Lighthouse**: برای ارزیابی جامع
- **NVDA/JAWS**: برای تست صفحه‌خوان

### سناریوهای تست
1. ناوبری کامل با صفحه‌کلید
2. استفاده با صفحه‌خوان
3. بزرگ‌نمایی صفحه
4. تغییر تنظیمات رنگ سیستم

## ۹. بهبودهای آینده

### برنامه‌ریزی آینده
- پشتیبانی از زبان‌های چندگانه
- بهبود تجربه صفحه‌خوان
- افزودن حالت‌های سفارشی دسترس‌پذیری

### بازخورد کاربران
- جمع‌آوری بازخورد از کاربران دارای نیازهای خاص
- بهبود مستمر بر اساس نیازهای واقعی
