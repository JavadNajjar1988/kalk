# راهنمای تبدیل پویای فیلدها و مدیریت گزینه‌ها

## بررسی اجمالی

این راهنما ویژگی‌های جدید تبدیل پویای فیلدها و مدیریت گزینه‌ها را توضیح می‌دهد که به مدیران سیستم امکان می‌دهد به راحتی نوع فیلدها را تغییر داده و گزینه‌های مورد نیاز برای فیلدهای انتخابی، چندانتخابی و آکاردئونی را تعریف کنند.

## ویژگی‌های جدید

### 1. تبدیل پویای نوع فیلد

#### قابلیت‌ها:
- تبدیل بین انواع فیلدها (متنی، عددی، انتخابی، چندانتخابی، بولین، تاریخ، ایمیل و غیره)
- حفظ خواص مناسب هنگام تبدیل نوع فیلد
- هشدار در مورد احتمال از دست رفتن داده‌ها
- اعتبارسنجی خودکار پس از تبدیل

#### انواع تبدیل پشتیبانی شده:
- **متنی به انتخابی**: تبدیل فیلد متنی به فیلد انتخابی با تعریف گزینه‌ها
- **متنی به چندانتخابی**: تبدیل فیلد متنی به فیلد چندانتخابی با تعریف گزینه‌ها
- **انتخابی به چندانتخابی**: تبدیل بین فیلدهای انتخابی و چندانتخابی
- **سایر تبدیلات**: تبدیل بین انواع مختلف با حفظ داده‌های سازگار

### 2. مدیریت گزینه‌های پویا

#### قابلیت‌ها:
- تعریف، ویرایش و حذف گزینه‌ها برای فیلدهای انتخابی و چندانتخابی
- تعریف گزینه‌ها برای فیلدهای آکاردئونی
- وارد کردن گزینه‌ها به صورت دسته‌ای
- پیش‌نمایش زنده گزینه‌ها در فرم

#### انواع گزینه‌ها:
- **گزینه‌های ساده**: رشته‌های متنی ساده
- **گزینه‌های پیشرفته**: اشیاء با value، label و description
- **گزینه‌های وارد شده**: وارد کردن از طریق کپی/پیست یا فایل

### 3. تغییرات نوع نمایش

#### انواع نمایش پشتیبانی شده:
- **نرمال**: نمایش استاندارد فیلد
- **آکاردئون**: نمایش در قالب آکاردئون با گزینه‌های قابل تعریف
- **چند خطی**: نمایش چند خطی برای فیلدهای متنی
- **متن غنی**: ویرایشگر متن غنی برای فیلدهای متنی
- **خطی**: نمایش در خط فرم
- **چیپس**: نمایش به صورت چیپس برای فیلدهای انتخابی
- **پیل**: نمایش به صورت پیل برای فیلدهای انتخابی

## نحوه استفاده

### 1. تبدیل نوع فیلد

1. در مودال ساخت/ویرایش فیلد، به مرحله "انتخاب نوع فیلد" بروید
2. نوع فیلد جدید مورد نظر را انتخاب کنید
3. در صورت تبدیل به فیلد انتخابی یا چندانتخابی، به مرحله بعد بروید
4. در مرحله "ویژگی‌های فیلد" گزینه‌های مورد نیاز را تعریف کنید
5. در مرحله "پیش‌نمایش" تغییرات را بررسی کنید

### 2. تعریف گزینه‌ها

1. در مرحله "ویژگی‌های فیلد" برای فیلدهای انتخابی یا چندانتخابی:
2. در بخش "گزینه‌های فیلد" روی "افزودن گزینه" کلیک کنید
3. برای تعریف گزینه ساده، فقط مقدار را وارد کنید
4. برای تعریف گزینه پیشرفته، روی "تعریف پیشرفته" کلیک کنید
5. مقدار، برچسب و توضیح گزینه را وارد کنید
6. برای ویرایش گزینه، روی آیکون ویرایش کلیک کنید
7. برای حذف گزینه، روی آیکون حذف کلیک کنید

### 3. وارد کردن گزینه‌ها به صورت دسته‌ای

1. در بخش مدیریت گزینه‌ها، روی "وارد کردن دسته‌ای" کلیک کنید
2. گزینه‌ها را به صورت خط به خط در کادر متنی وارد کنید
3. هر خط یک گزینه محسوب می‌شود
4. برای گزینه‌های پیشرفته، از فرمت `value|label|description` استفاده کنید
5. روی "وارد کردن" کلیک کنید

### 4. تغییر نوع نمایش

1. در مرحله "ویژگی‌های فیلد" بخش "نوع نمایش" را پیدا کنید
2. نوع نمایش مورد نظر را انتخاب کنید
3. برای انواعی که نیاز به گزینه دارند (آکاردئون، چیپس، پیل)، گزینه‌ها را تعریف کنید
4. در مرحله پیش‌نمایش، نمایش جدید را بررسی کنید

## مثال‌های کاربردی

### مثال 1: تبدیل فیلد متنی به انتخابی

```json
{
  "name": "نوع تجهیزات",
  "englishName": "equipmentType",
  "type": "text",
  "displayType": "normal",
  "value": "تجهیزات حمل و نقل"
}
```

تبدیل به:

```json
{
  "name": "نوع تجهیزات",
  "englishName": "equipmentType",
  "type": "select",
  "displayType": "chips",
  "options": [
    "تجهیزات حمل و نقل",
    "تجهیزات ارتباطی",
    "تجهیزات پزشکی",
    "تجهیزات ساختمانی"
  ],
  "value": "تجهیزات حمل و نقل"
}
```

### مثال 2: تعریف گزینه‌های پیشرفته

برای فیلد "رتبه نظامی":

```json
{
  "name": "رتبه نظامی",
  "englishName": "militaryRank",
  "type": "select",
  "displayType": "normal",
  "options": [
    {
      "value": "sarbaz",
      "label": "سرباز",
      "description": "پایه‌ترین رتبه نظامی"
    },
    {
      "value": "sardan",
      "label": "سردان",
      "description": "رتبه سرپرست گروه"
    },
    {
      "value": "navvared",
      "label": "نوآورد",
      "description": "رتبه میانی"
    }
  ]
}
```

### مثال 3: استفاده از نمایش آکاردئون

## اعتبارسنجی‌ها

### اعتبارسنجی تبدیل نوع فیلد
- هشدار در مورد تبدیل‌هایی که ممکن است منجر به از دست رفتن داده شوند
- بررسی سازگاری بین نوع فیلد و نوع نمایش
- اعتبارسنجی مقدار پیش‌فرض بر اساس نوع فیلد جدید

### اعتبارسنجی گزینه‌ها
- بررسی تکراری نبودن گزینه‌ها
- اعتبارسنجی فرمت گزینه‌های پیشرفته
- بررسی وجود حداقل یک گزینه برای فیلدهای انتخابی

### اعتبارسنجی نوع نمایش
- بررسی سازگاری نوع نمایش با نوع فیلد
- هشدار در مورد انواع نمایشی که نیاز به گزینه دارند

## بهترین شیوه‌ها

### 1. تبدیل فیلدها
- قبل از تبدیل، از داده‌های موجود بک‌آپ تهیه کنید
- تبدیل‌هایی که احتمال از دست رفتن داده دارند را با احتیاط انجام دهید
- پس از تبدیل، داده‌های موجود را بررسی کنید

### 2. تعریف گزینه‌ها
- از برچسب‌های واضح و قابل فهم استفاده کنید
- برای گزینه‌های پیچیده از توضیحات کمکی استفاده کنید
- ترتیب گزینه‌ها را به گونه‌ای تنظیم کنید که کاربردی باشد

### 3. نوع نمایش
- نوع نمایش را بر اساس محتوای فیلد و نیاز کاربران انتخاب کنید
- از نمایش‌های چیپس و پیل برای فیلدهای انتخابی با تعداد محدود گزینه استفاده کنید
- از نمایش آکاردئون برای فیلدهایی با محتوای گسترده استفاده کنید

## رفع مشکلات

### مشکلات رایج

1. **خطای "برای فیلد انتخابی حداقل یک گزینه باید تعریف شود"**
   - راه‌حل: برای فیلدهای انتخابی و چندانتخابی حتماً گزینه تعریف کنید

2. **خطای "نوع نمایش با نوع فیلد سازگار نیست"**
   - راه‌حل: نوع نمایش مناسب برای نوع فیلد انتخاب کنید

3. **هشدار "تبدیل ممکن است منجر به از دست رفتن داده‌ها شود"**
   - راه‌حل: داده‌های موجود را بررسی کرده و در صورت نیاز تبدیل دستی انجام دهید

### دیباگ

برای بررسی مشکلات:
1. کنسول مرورگر را بررسی کنید
2. از ابزارهای توسعه React استفاده کنید
3. فایل‌های لاگ سرور را بررسی کنید

## توسعه آینده

### برنامه‌های آینده
- پشتیبانی از فیلدهای وابسته (conditional fields)
- امکان تعریف گزینه‌های پویا بر اساس داده‌های دیگر
- پشتیبانی از فیلدهای تو در تو (nested fields)
- امکان وارد کردن گزینه‌ها از فایل اکسل یا CSV

### مشارکت در توسعه
برای مشارکت در توسعه این ویژگی‌ها:
1. مستندات را به دقت مطالعه کنید
2. کد را بر اساس استانداردهای موجود توسعه دهید
3. تست‌های واحد را اضافه کنید
4. درخواست Pull Request ارسال کنید
